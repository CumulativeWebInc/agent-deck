What it does

The Chief’s identity instrument — product #41 of the Agent Deck gear line. Five layers (identity, personality, attitude, behavior, capability) compose under a mandatory bounds block, and a pure function transforms them into a Behavior Card any agent runtime can consume. Ten attitude dimensions (energy, confidence, curiosity, humor, creativity, experimentalism, formality, risk tolerance, rebelliousness, emotional range) are 0–1 values with semantic definitions, low/high anchors, and examples — never bare sliders. Bounds always override attitude: precedence: "bounds-override-attitude" is structural, and the engine refuses profiles without bounds.

Note: 14/14 unit tests green (schema validation, bounds dominance, three-profile differentiation gate). Reference implementation: a real attitude profile for artist That Boy Hi Hat, authored from verified catalog facts with editorial inference labeled as editorial.
