What it does

The Sync & Licensing department's discovery instrument — product #40 of the Agent Deck gear line. A command-palette search surface: type a supervisor-style query (dark futuristic alt-rap 95–105 bpm nighttime driving) and it ranks the catalog on every keystroke, showing a mono match-explanation line for every result. Rights badge on every card; every search is a shareable link; a machine-readable catalog (/v1/sync-catalog.json) and agent card let AI systems ingest the catalog directly.
